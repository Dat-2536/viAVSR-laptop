# viASVR-laptop

Vietnamese Audio-Visual Speech Recognition project for laptop-based Record-and-Infer transcription.

## Sprint 1 goal

Reproduce the released Vietnamese AVSR baseline in a reproducible environment,
run an official Vietnamese sample through the correct checkpoint/tokenizer,
and evaluate the transcript with WER/CER.

## Sprint 1 scope

- Project/repository setup
- Official asset verification
- Reproducible environment
- Vietnamese checkpoint + tokenizer loading
- Official-sample inference
- Vietnamese WER/CER evaluation

Out of scope for Sprint 1:
- raw laptop mouth-ROI preprocessing
- frontend
- fine-tuning
- dataset collection
- Docker packaging
